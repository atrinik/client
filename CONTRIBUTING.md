# Independent implementation

Direct human-written code contributions are welcome. The project currently
develops software primarily through Codex-driven agentic workflows, but changes
written by people or agents follow the same accountable review, clean-room,
provenance, licensing, testing, and repository-validation requirements.

Client code is newly authored MIT work from public specifications, observable
behavior, interoperability facts, synthetic fixtures, independently licensed
data, and permissive dependencies. Do not consult GPL source/tests as an
implementation template or copy, transliterate, mechanically translate, or
preserve their structure. Mixed content/assets remain external under their own
terms and never become MIT by association.

Every module, reused file, behavior-only migration, generated input, fixture,
and asset updates `PROVENANCE.md` and the machine manifests. Historical reuse
requires the exhaustive wrapper grantor registry plus complete non-shallow
rename-aware history, sole original authorship/identity proof, separability,
third-party/conflicting-notice review, exact paths/revisions/transformation, and
the exact wrapper registry revision. Uncertainty fails closed.

Pull requests confirm: no unrecorded GPL input; exact authorship/design inputs;
generated input/tool/drift evidence; fixture and asset licenses/digests/notices;
dependency/native policy; bounded failure/privacy behavior; and
`tools/validate.sh`.
