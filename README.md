# Atrinik client

This repository is the fresh, clean-room Atrinik game client implemented in Rust with SDL3.

New source code in this repository is licensed under the MIT License. Shared GPU rendering lives in [atrinik/renderer](https://github.com/atrinik/renderer). The classic GPL client is maintained in the [`client/` module of atrinik/classic](https://github.com/atrinik/classic/tree/main/client); do not copy, translate, or adapt its source code.

The implementation roadmap is tracked by [atrinik/atrinik#168](https://github.com/atrinik/atrinik/issues/168).
